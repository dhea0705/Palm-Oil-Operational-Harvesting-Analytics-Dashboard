# Palm-Oil-Operational-Harvesting-Analytics-Dashboard
Memantau efisiensi pemanen dan risiko penurunan kualitas minyak CPO akibat FFA tinggi.
Teknologi yang Digunakan: Python, Pandas, Streamlit, Plotly, SQL.
Insight Utama yang Ditemukan: Ringkasan temuan analisis (seperti perbedaan produktivitas wilayah dan dampak status pengiriman 'Tertunda' terhadap nilai FFA).
